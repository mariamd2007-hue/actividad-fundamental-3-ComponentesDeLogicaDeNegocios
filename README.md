En esta actividad se implementaron los principios de Domain-Driven Design. Asi como utilizamos la IA como herramienta de apoyo para poder agilizar la estructuración y validación de componentes, sin embargo las decisiones de diseño, la validación de reglas de negocio y el cumplimiento de los principios SOLID estuvieron bajo nuestra revisión.
En este GitHub pusimos los diagramas principales asi como el ADR, en los diagramas están incluidos el DDD, el de clases y el de secuencia.
En Netacad se entregaron dos archivos donde en ambos está en link de este documento, un documento muestra las capturas de los archivos de este documento, y en el otro es el informe completo de la actividad y ahí están todos y cada uno de los diagramas y tablas que se encuentran en este documento. Para mayor comprensión recomendamos leer el informe ya que es mas completo y contiene mas contexto sobre las tablas y explicamos el porque de cada uno de nuestras decisiones.

Incluimos el diagrama de clases dos veces, una vez en el de ddd y otra individualmente para mejor visualización.
